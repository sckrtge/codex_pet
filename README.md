# codex娘 · ChatGPT 虚拟宠物

基于 [ZipZipPipe 发布的 codex娘设定图（第三张）](https://www.bilibili.com/opus/1238613841710940181)进行的 AI 辅助 Q 版改绘与动画适配。非 OpenAI 官方角色或官方发布。

![拖拽与挥手预览](preview/changes-preview.gif)

## 动作

| 状态 | 表现 |
| --- | --- |
| 待机 | 坐着使用电脑、写代码 |
| 开始思考 | 暂停打字，挠头思考 |
| 欢迎 / 悬停互动 | 手臂持续举起，左右挥手 |
| 左右拖拽 | 同一套拱背前倾、双手双脚下垂的动作 |
| 等待 / 受阻 / 待查看 | 对应的坐姿表情动作 |
| 视线 | 十六方向观察 |

动作触发与持续时间由 ChatGPT 客户端控制；动画资源不会改变客户端逻辑。思考动作并不保证持续到整轮任务结束。

## 文件与使用

- [完整透明动画图集](assets/spritesheet.png)：v2，1536 × 2288，8 列 × 11 行，每格 192 × 208。
- [全部状态预览](preview/all-states.gif) · [视频预览](preview/all-states.mp4)
- 每行有效帧数：`6, 8, 8, 4, 5, 8, 6, 6, 6, 8, 8`。
- 图集是宠物资源文件，不是独立桌面程序，也不是可执行安装包。

### 快速导入

1. 在支持自定义宠物、且已连接相应宠物工具的 ChatGPT / Work / Codex 环境中打开对话。
2. 下载上面的「完整透明动画图集」，将 PNG 原文件附给 Codex，并发送下面的导入提示词。不要用 GIF、视频或截图代替图集。
3. 导入完成后，让 Codex 确认宠物名称为「codex娘」，并将它设为当前宠物；需要桌面显示时，在客户端头像菜单中打开「显示虚拟宠物」（入口名称以客户端版本为准）。

**也可以直接把仓库地址复制给 Codex**，让它读取仓库、下载现成图集并导入，无需自己整理文件：

```text
请将这个仓库的现成宠物导入并设为当前宠物：
https://github.com/sckrtge/codex_pet

宠物名称：codex娘。
使用仓库里的 assets/spritesheet.png 原文件，这是 v2 动画图集。
请先读取 README 的图集规格，验证后通过可用的宠物工具导入，保留所有动画帧和十六方向视线帧。
不要重新生成、重画或裁切图集，不要修改客户端程序。
完成后请确认导入结果和当前选中的宠物。
```

导入依赖客户端提供的自定义宠物能力及相应宠物工具；复制仓库地址本身不是安装程序，也不会自动启用客户端尚未开放的功能。若当前环境没有导入入口，请先在支持该能力的客户端中连接宠物工具，再使用上述提示词。
